# VS Code AI Workshop for Non-Developers

비개발자를 위한 VS Code + GitHub Copilot 핸즈온 자료입니다.

목표는 코딩을 배우는 것이 아니라, VS Code를 AI 작업실로 사용해 내 업무 폴더를 팀 전용 AI 비서처럼 구성하는 것입니다.

## Core Idea

자동화 도구가 없어도 자동화는 시작할 수 있습니다.

1. 업무 내용을 모은다: `inbox/`
2. AI에게 규칙을 준다: `prompts/`
3. 결과를 구조화한다: `outbox/*.json`
4. 나중에 실행 도구를 붙인다: Power Automate, Zapier, Make, 사내 시스템

## Suggested Session Flow

- 0-10분: 오프닝, 비개발자의 Copilot 사용 사례 소개
- 10-25분: VS Code 기본 조작
- 25-45분: Copilot Chat, Edit, Agent Mode 개념
- 45-65분: 내 업무 폴더를 AI 작업실로 만들기
- 75-100분: 업무 프롬프트와 `outbox/*.json` 만들기
- 100-115분: 작은 AI 비서 워크플로우 설계
- 115-120분: 정리와 다음 단계
