# 실습 데이터 참조

## 사용 데이터

이 저장소의 `data/marketing-campaign.csv`는 UCI Machine Learning Repository의 **Bank Marketing** 데이터셋을 실습용으로 샘플링한 파일입니다.

- 원본: https://archive.ics.uci.edu/dataset/222/bank+marketing
- 원본 설명: 포르투갈 은행의 정기예금 상품 전화 마케팅 캠페인 데이터
- 원본 규모: 45,211건
- 실습 파일: 원본에서 4,521건을 고정 시드로 샘플링
- 목표 변수: `y`
  - `yes`: 고객이 정기예금 상품에 가입
  - `no`: 가입하지 않음

## 주요 컬럼

- `age`: 고객 나이
- `job`: 직업
- `marital`: 결혼 상태
- `education`: 교육 수준
- `balance`: 계좌 잔고
- `housing`: 주택담보대출 여부
- `loan`: 개인대출 여부
- `contact`: 연락 방식
- `day`, `month`: 마지막 연락 일자
- `duration`: 마지막 통화 시간(초)
- `campaign`: 이번 캠페인에서 해당 고객에게 연락한 횟수
- `pdays`: 이전 캠페인 이후 지난 일수 (`-1`은 이전 접촉 없음)
- `previous`: 이전 캠페인 접촉 횟수
- `poutcome`: 이전 캠페인 결과
- `y`: 정기예금 가입 여부

## 실습에서 볼 만한 질문

```text
가입률이 높은 직업군과 낮은 직업군을 비교해줘.
연락 방식별 가입률을 표로 정리해줘.
주택담보대출 여부가 가입률에 어떤 차이를 만드는지 분석해줘.
통화 시간이 긴 고객과 짧은 고객의 가입률 차이를 설명해줘.
이번 데이터 기준으로 다음 캠페인 타깃팅 전략 3가지를 제안해줘.
```
