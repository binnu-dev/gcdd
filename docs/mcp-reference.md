# MCP 참조 정보

확인일: 2026-04-25

## 다이소 MCP

- GitHub: https://github.com/hmmhmmhm/daiso-mcp
- 원격 MCP URL: `https://mcp.aka.page/mcp`
- 프롬프트/HTTP API 참고 페이지: `https://mcp.aka.page/prompt`

확인할 수 있는 내용:

- 다이소: 상품 검색, 매장 검색, 매장별 재고, 일부 상품 진열 위치
- 올리브영: 매장 검색, 상품/재고 확인
- 편의점/마트: CU, GS25, 세븐일레븐, 이마트24, 롯데마트 매장·상품·재고 확인
- 영화관: CGV, 메가박스, 롯데시네마 지점·영화·상영시간·잔여 좌석 확인

실습 질문 예시:

```text
다이소 MCP를 사용해서 강남역 근처 매장을 찾아줘.
다이소 MCP를 사용해서 수납박스 상품을 검색하고, 강남역 근처 매장 재고를 확인해줘.
올리브영 MCP를 사용해서 명동 근처 매장을 찾고 선크림 재고를 확인해줘.
CGV MCP를 사용해서 오늘 강남 CGV 상영 영화와 시간표를 알려줘.
```

## DART MCP

추천 서버: Dayoooun/dart-mcp

- GitHub: https://github.com/Dayoooun/dart-mcp
- 원격 URL: `https://dart-mcp-self.vercel.app/sse`
- 특징: Vercel에 이미 배포되어 있어 별도 배포 없이 바로 사용 가능
- 지원 데이터: 2023년 ~ 2025년
- 기업 데이터: 114,951개 기업

제공 도구 범위:

- 기업 검색
- 공시 검색
- 기업 기본정보
- 주요 재무계정
- 전체 재무제표
- 재무지표
- 배당 정보
- 임원 현황
- 직원 현황
- 최대주주 현황
- 대량보유 상황보고
- 임원·주요주주 지분 변동
- 증자/감자 현황
- 자기주식 취득/처분 현황

실습 질문 예시:

```text
DART MCP로 삼성전자와 카카오를 찾아서 최근 3개년 매출과 영업이익을 비교해줘.
네이버의 2023년 연간 재무제표를 가져와서 핵심 지표를 표로 정리해줘.
카카오 직원 현황과 평균 급여 정보를 가져와서 마케팅팀 보고서용 요약을 써줘.
```
