Step 2A

2단계 — Instructions + Prompts (30분)

먼저 만드는 파일

  • .github/copilot-instructions.md 작성
  • .github/prompts/weekly-report.prompt.md 작성
  • /weekly-report 실행
  • .github/prompts/monthly-report.prompt.md 도 예제로 보여주기
핵심은 Sean의 기본 맥락을 만들고, 반복 업무를 slash prompt로 고정하는 것입니다.

mode: agent
description: 이번 주 마케팅 성과 보고서 초안 작성
---

data/marketing-campaign.csv를 읽고
가장 최근 데이터를 기준으로
주간 마케팅 성과 보고서를 작성해주세요.

Step 4

4단계 — Skills (20분)

실습 항목

  • Agent Browser 써보기
  • Frontend Design Skill 써보기
  • HTML 보고서 만들기
  • Skill Creator 구조 살짝 보기
  • prompt vs skill 비교 실험

이 단계에서 같이 짚을 것

  • Instructions / Prompts / Skills 차이
  • hook / agent 같은 기능은 살짝 소개만
  • Anthropic 공식 skill 예제 열어보기
  • frontend-design, skill-creator
Skill을 먼저 써본 뒤에 비교합니다: Instructions는 기본 맥락, Prompts는 작업 호출, Skills는 전문성 장착입니다.
예시: `/monthly-report` prompt로 먼저 월간 HTML 보고서를 만들고, 그 다음 `.github/skills/monthly-report-template/` 안의 brief + template + script를 쓰게 한 뒤 같은 HTML 보고서를 다시 만들어 결과 차이를 비교합니다.
포인트: prompt도 같은 결과물을 만들 수는 있지만, skill은 구조와 스타일과 분석 기준까지 더 정확하게 고정합니다.

5단계 — 팀 공유 체험 + 마무리 (15분)

팀 공유 체험

  • 오늘 만든 구조를 자기 팀에 복제하기
  • 공유 문서를 팀 자산으로 남기기
  • Sean을 자기 팀 맥락으로 치환하기

Wrap-Up

오늘 참가자들이 이해하면 되는 것

  • Sean은 공통 AI 비서 페르소나이고, 실습은 가상 팀으로 진행한다
